When does a language need types, and when does it need contracts?

It's a question worth sitting with, because the answer reveals something about how we think about correctness itself. Static types catch errors before execution. Contracts catch them at the boundary between trust and the unknown. They operate in fundamentally different problem spaces, and conflating them is how you end up disappointed by both.

This library brings contract-style validation to Nix. The mechanism is almost disappointingly simple. A type is a function that takes data and returns a boolean. That's it. You wrap your validators in a declare call that adds a name and some tracing infrastructure, compose them with combinators like not and enum and listOf, and then you apply them at the points where untrusted data enters your system. The package dot json example in the article is the right instinct — you're not typing your entire Nix expression, you're validating the boundary where external JSON meets your derivation logic.

The Nix community comment split is instructive. One response calls runtime assertions a poor substitute for a type system. And that's technically correct — but it misses the point. Nobody is proposing this as a replacement for Dhall or Nickel. Those languages were designed from scratch with type systems. Nix wasn't. Nix has millions of lines of existing code in nixpkgs, and nobody is rewriting that corpus in a different language. The question isn't whether static types are superior in the abstract. The question is what you can retrofit onto a running system without stopping the world.

This is where contracts earn their place. They're defensive engineering at system boundaries. You don't need to type every internal function if you can guarantee that data entering your system conforms to a known shape. It's the same principle behind input validation in any security-conscious codebase. Trust the interior, verify the perimeter. The library is open source, composable, and compatible with the existing Nix ecosystem. No revolution required. Just a checkpoint where you need one.
